# MERN Real Estate App

Full-stack real estate application built with the **MERN stack**, including **real-time chat using Socket.io**, authentication with **JWT + HTTP-only cookies**, and a modern React architecture.

---

## Tech Stack

**Frontend**
- React
- React Router DOM
- Context API
- Sass (SCSS)
- Socket.io Client

**Backend**
- Node.js
- Express
- MongoDB
- Prisma ORM
- Socket.io
- JWT (cookie-based auth)

---

## Features

- User authentication and protected routes
- Property listings (CRUD)
- Real-time private chat
- Global state management
- Responsive UI
- Prisma-based database access

---

## Project Structure

client/   React frontend
server/   Node.js backend
prisma/   Database schema
